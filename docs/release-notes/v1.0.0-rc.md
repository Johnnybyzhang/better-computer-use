# Better Computer Use v1.0.0-rc

Release candidate for persistent shared desktops and the redesigned PiP viewer.

## Changes

- Agents can reconnect, observe, or hand off the same child desktop without closing applications. Detaching an agent leaves the desktop running.
- Borderless, topmost PiP with a soft connection indicator, hover controls, and two-click human takeover.
- Expanded view preserves desktop aspect ratio and reserves space for controls. Narrow portrait desktops keep both actions accessible.
- Custom settings provide independent click-out collapse and automation-resume choices.
- Shared-host capability discovery reflects user mode and elevation settings. Destructive logoff validates active ownership.
- Reconnect preserves saved desktop dimensions; stale viewer events cannot fault a replacement session.
- Branded application/tray icons and corrected taskbar hide/restore behavior.

## Validation

71 local checks passed inside the child desktop; the noninteractive subset passed 47 checks. Live tests covered inner-helper input, fresh-client discovery, handoff and preservation of unsaved applications across host recovery. CodeQL and Windows x64/ARM64 builds passed for the merged implementation.

## Installation and limitations

Choose the win-x64 or win-arm64 bundle, extract it, and run Install.cmd as a standard user. The installed OpenAI Computer Use runtime is required and is not included.

This is a prerelease. Full interactive Windows on ARM, multi-monitor/DPI transitions, screenshot-tool interactions and manual UAC scenarios still need broader validation. The previously observed intermittent session-stop cleanup hang remains unresolved. Binaries are unsigned. See docs/validation.md for details.
