# Better Computer Use v0.1.5

Initial public release of a Windows child-session backend for ChatGPT/Codex Computer Use.

## What it does

Keep the agent and steering UI on your main desktop while the installed Computer
Use executable operates applications in a separate Windows child session. You can
continue using your mouse to steer the agent without reclaiming its automated desktop.

- Session-bound MCP adapter with the bundled helper's named capture, UI Automation,
  input, application and audio tools.
- Independent MCP connections per task, with one exclusive child-desktop owner.
- Persistent elevated Computer Use by default, initialized through main-session UAC.
- Explicit user-space mode and fallback when initialization UAC is declined;
  administrator tools are removed in user mode.
- Separate main-session UAC for explicit administrator application launch, with
  process/session/elevation verification before a suspended application runs.
- Disconnected-session logoff recovery, helper restart and generation checks.
- Optional View / Take control viewer, without extra per-app or per-click prompts.

## Downloads and installation

Choose the **win-x64** ZIP for Intel/AMD Windows or **win-arm64** for Windows on ARM.
Extract the entire ZIP, run `Install.cmd` as a standard user, and start a new task in
the desktop app. The bundle includes .NET and verifies its file checksums.

**OpenAI's Computer Use executable is not included.** Initialize Computer Use in your
own compatible ChatGPT/Codex installation first. Native Windows child-session support,
Task Scheduler and the RDP ActiveX control are required. Windows Home is excluded
by default; macOS should use its built-in Computer Use.

## Validation and limitations

The local review passed 51 automated checks, 42 noninteractive CI-subset checks,
five release-policy tests and workflow linting. Live x64 tests covered persistent
admin and user modes, helper calls/restart, admin-tool removal and disposable-session
logoff. CI builds and verifies both architecture bundles before publication.

This is an early release. The UI is functional but unpolished. A previously observed
intermittent session-stop cleanup hang remains unresolved. ARM64 compilation and
native CI smoke checks do not establish full RDP/OpenAI-helper compatibility on real
Windows on ARM hardware. A real user-declined UAC fallback remains an interactive
validation item; the fallback logic is covered by automated tests.

Binaries are unsigned. Child sessions share your account and files; they are not a
VM or a security boundary. The private OpenAI helper protocol can change with app updates.
